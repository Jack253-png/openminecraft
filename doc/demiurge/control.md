# Demiurge UI Controls
## Button
### Styles
| Key Name | type | Description |
| ----------- | ----------- | ---------- |
| animation_speed | float | animation speed in seconds |
| label | std::string | content of the button |
| opacity_normal | float | normal opacity of the button |
| opacity_hovered | float | opacity of a hovered state |
| opacity_clicked | float | opacity of a clicked state |
| radius | glm::vec4 | radius of the button background |
